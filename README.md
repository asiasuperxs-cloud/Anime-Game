## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ | ต้องแก้ไหม |
|---|---|---|
| `index.html` | หน้าเว็บ, เมนู, หลอดเลือด | ไม่ค่อย |
| `game.js` | เอนจินเกม (ฟิสิกส์, การชน, CPU, กล้อง 3D) | ไม่ค่อย |
| `characters.js` | **ข้อมูลตัวละครและท่าทั้งหมด** | แก้ไฟล์นี้ตอนเพิ่มตัวละคร |

| `check-bot.js` | CheckBot แบบรันในเครื่อง | ไม่ต้อง |
| `.github/workflows/check-bot.yml` | CheckBot บน GitHub (รันทุกครั้งที่ commit) | ไม่ต้อง |

## วิธีแก้ไฟล์บนเว็บ (ไม่ต้องลงโปรแกรม)
1. เข้า https://github.com/asiasuperxs-cloud/Anime-Game
2. กดไฟล์ที่จะแก้ เช่น `characters.js` แล้วกดรูปดินสอ (Edit)
   - หรือกดปุ่ม `.` บนคีย์บอร์ดในหน้า repo จะเปิดโปรแกรมแก้โค้ดเต็มรูปแบบ (github.dev)
3. แก้เสร็จกด **Commit changes...** แล้วกด Commit อีกครั้ง
4. ดูแท็บ **Actions** — CheckBot จะขึ้น ✓ (ผ่าน) หรือ ✗ (มี error กดเข้าไปดูว่าผิดตรงไหน)
5. รอ 1–2 นาที แล้วรีเฟรชหน้าเกม (ถ้าไม่เปลี่ยนให้กด Ctrl+Shift+R)

## เพิ่มตัวละคร
1. เปิด `characters.js` คัดลอกตัวละครหนึ่งตัว `{ ... }` ไปวางต่อท้าย (คั่นด้วย comma)
2. เปลี่ยน `id` (ห้ามซ้ำ, ตัวพิมพ์เล็ก), `name`, `color`, `stats`, `moves`
3. Commit แล้วดูผล CheckBot

## CheckBot — 3 ชั้น
1. **บน GitHub:** แท็บ Actions ขึ้น ✓ / ✗ ทุกครั้งที่ commit
2. **ในเว็บเกม:** ปุ่มมุมซ้ายล่างบอกผลตรวจ ตัวละครที่มี error จะไม่ถูกโหลด (เกมไม่พังทั้งเกม)
3. **ในเครื่อง (ถ้าลง Node.js):** `node check-bot.js` หรือ `node check-bot.js --watch` ให้ตรวจทุกครั้งที่กดเซฟ

สิ่งที่บอทตรวจ: syntax พัง (ลืม comma/วงเล็บ) พร้อมเลขบรรทัด, field ขาด, ชนิดข้อมูลผิด (เช่น `"1.7"` แทน `1.7`),
สะกดผิดพร้อมเดาคำที่ถูก, ค่าเกินช่วง, id ซ้ำ, สีผิดรูปแบบ, input ผิดรูปแบบ, ปุ่มท่าชนกัน, ท่ายิงที่ขาด projectileSpeed

## ปุ่มเล่น (สนาม 3D เดินได้รอบทิศ)
- P1: เดิน W A S D · กระโดด Space · ต่อย F · เตะ G · สกิล1 H · สกิล2 J · อัลติ R
- P2: เดิน ลูกศร · กระโดด Shift ขวา · ต่อย , · เตะ . · สกิล1 / · สกิล2 ; · อัลติ '
- เดินถอยหลังหนีคู่ต่อสู้ = กัน · เดินเข้า/ออกจอ = หลบด้านข้าง
- อัลติใช้ได้เมื่อเกจใต้หลอดเลือดเต็ม (เกจขึ้นเมื่อตีโดนหรือโดนตี)
